# 굴곡 카메라 실습 프로젝트

## 시작

`Tools > Camera Tutorial > 1. Create or Open Tutorial`을 선택합니다.

## Hierarchy 순서

1. `[01] GUIDE` — 미션과 설명
2. `[02] CAMERAS` — Main, Distortion, Player Camera
3. `[03] LEVEL` — Grid, Ground Tilemap, Hazards Tilemap
4. `[04] PLAYER` — Sprite, Rigidbody2D, Collider, PlayerController
5. `[05] RUNTIME OUTPUT` — Play 중 생성되는 화면 Quad와 카메라

## 안전장치

- 변경 전 백업: `Tools > Camera Tutorial > 2. Save Checkpoint`
- 백업 복원: `Tools > Camera Tutorial > 3. Restore Checkpoint`
- 완전 초기화: `Tools > Camera Tutorial > 4. Reset Working Scene`

원본 게임 씬은 건드리지 않고 `CameraTutorial_Working` 씬에서만 연습합니다.

## 교육용 맵

- 가시는 제거되어 있습니다.
- 기존 맵 오른쪽에 완만한 길이 추가됩니다.
- 높이는 한 번에 한 칸씩만 변합니다.
- 진행을 막는 긴 수직 벽이나 낮은 천장은 없습니다.
- 짧은 보조 발판으로 점프와 카메라 이동을 연습할 수 있습니다.
