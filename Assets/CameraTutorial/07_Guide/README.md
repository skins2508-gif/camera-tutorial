# 7단계 — 구조 해설과 확장 아이디어

완성된 Main Camera, RenderTexture, Screen Quad, Distortion Camera, Player Overlay Camera의 역할을 읽고 정리하는 단계입니다.

게임 안에서 사용할 수 있는 이동, 2단 점프, 재시작, Q UI 숨기기, W 유니티 엔진 설명서, 페이지 이동, 단계 이동, 굴절 비교, 최종 완료 키도 한곳에 정리합니다.

앞으로 추가하면 좋은 기능으로 부드러운 추적, 카메라 범위, 해상도 자동 변경, Material 에셋화, 구간별 굴곡, 전환 애니메이션, UI Overlay, 화면 흔들림, 체크포인트, 성능 표시를 소개합니다.

설명서를 모두 읽었으면 숫자 `8`을 눌러 최종 완료 단계로 이동합니다. 폭죽은 8단계에서 실행합니다.
